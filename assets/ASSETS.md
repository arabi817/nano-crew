# 그림 목록 (ASSETS.md)

이 게임의 그림은 **그림 파일이 있으면 그 그림을, 없으면 코드로 그린 그림을** 써요.
그림을 하나씩 바꿔 끼워도 게임이 깨지지 않아요.

## 그림을 넣는 방법

1. 아래 표의 **파일 이름 그대로** 알맞은 폴더에 넣어요.
2. `python3 tools/art/update_list.py` 를 실행하면 `assets/list.js` 목록이 폴더 내용대로 다시 만들어져요. (목록에 없으면 불러오지 않아요)
3. GitHub main에 올리면 1~2분 뒤 Vercel에 반영돼요.
4. 그림을 빼고 코드 그림으로 되돌리려면 파일을 지우고 2번을 다시 하면 돼요.

## GPT 원본 → 게임 그림 도구 (`tools/art/`, Pillow·numpy 필요)

| 도구 | 하는 일 |
|---|---|
| `make_body.py assets/_raw/body_master.webp 12` | 몸통 원본 → 굵은 테두리 + 12색 + 안테나 없는 판 |
| `make_parts.py` | `foot_master.png` → 발 12색, `hat1~5_master.png` → 몸통 칸에 맞춘 모자 |
| `make_map.py [이름…]` | 바닥·복도·벽(jpg), 소품·장치·로고(투명 png). 이름을 주면 그것만 |
| `update_list.py` | `assets/list.js` 다시 만들기 |

- 초록 물건(미토콘드리아·새싹·미션 장치)은 **마젠타(#ff00ff) 배경**으로 그려야 배경 지울 때 같이 안 지워져요. 도구가 구석 색을 보고 알아서 판단해요.

## 공통 규칙

- 스타일: **아주 굵은** 진한 외곽선(#1a1018, 어몽어스 정도의 두께) + 단색 면 + 간단한 명암 1단계. 캐주얼 게임 스티커 느낌.
- 금지: 어몽어스 그림·모양 베끼기(콩 모양 몸, 가로 바이저, 등 가방), 이모지, 글자(로고 제외).
- **투명** 그림은 GPT가 초록 단색 배경으로 그린 뒤 배경을 지워서 만들어요.
- 크기는 화면에 보이는 크기보다 크게 만들어요(캐릭터 4배, 소품·장치 2배). 코드가 알맞게 줄여요.
- GPT 원본은 `assets/_raw/`에 WebP(화질 92, 용량 절약)로 보관하고, 원본에서 게임용 그림을 만드는 도구는 `tools/art/`에 있어요.
