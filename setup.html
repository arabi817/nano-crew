내 서버 만들기

다른 학교 선생님이 어몸어스를 쓰실 때, 학생들이 접속할 무료 서버(Firebase)를 선생님 구글 계정으로 하나 만들어요. 처음 한 번만, 10~15분이면 돼요.

왜 필요해요?무료 서버 하나는 동시 접속 100명까지예요. 학교마다 자기 서버를 쓰면 서로 막히지 않아요.
돈이 드나요?아니요. 무료(Spark) 요금제로 충분하고 카드 등록도 필요 없어요.
학생 정보는요?이름·이메일을 받지 않아요. 닉네임과 게임 진행만 잠깐 저장돼요.

1프로젝트 만들기

  1. Firebase 콘솔에 구글 계정으로 들어가요.
  2. 프로젝트 만들기(또는 '프로젝트 추가')를 눌러요. 이름은 예) amomus-우리학교
  3. Google 애널리틱스는 꺼요 → 프로젝트 만들기

버튼 이름은 구글이 가끔 바꿔요. 비슷한 이름을 찾으면 돼요.

2익명 로그인 켜기

  1. 왼쪽 메뉴 빌드(Build) → Authentication → 시작하기
  2. 로그인 방법(Sign-in method) 탭 → 익명(Anonymous) → 사용 설정 켜고 저장

학생이 이름·이메일 없이 들어오게 해 주는 기능이에요.

3실시간 데이터베이스 만들기

  1. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기
  2. 위치: 싱가포르 (asia-southeast1) (한국에서 가장 가까워요)
  3. 보안 규칙: 잠금 모드로 시작 → 사용 설정

4보안 규칙 붙여 넣기

  1. Realtime Database 화면 위쪽 규칙(Rules) 탭
  2. 안의 글을 모두 지우고, 아래 버튼으로 복사한 규칙을 붙여 넣어요.
  3. 게시(Publish)
복사했어요!

학생이 개발자 도구로 들여다봐도 누가 바이러스인지 알 수 없게 막아 주는 규칙이에요.

5웹 앱 등록하고 설정값 복사

  1. 왼쪽 위 톱니바퀴 → 프로젝트 설정
  2. 아래쪽 '내 앱'에서 웹 아이콘 </> → 앱 닉네임 아무거나 → Firebase Hosting은 체크하지 않기 → 앱 등록
  3. 화면에 나온 const firebaseConfig = { apiKey: "...", ... }; 부분을 통째로 복사해요.

이 값은 비밀번호가 아니라 '서버 주소' 같은 거라 학생 링크에 들어가도 괜찮아요. 보안은 4단계 규칙이 지켜요.
databaseURL이 안 보이면 Realtime Database 화면 맨 위의 https://…firebasedatabase.app 주소도 함께 복사해 두세요.

6교사 화면에 붙여 넣기

  1. 교사 화면을 열고 첫 화면 아래 [내 서버 연결하기]
  2. 5단계에서 복사한 글을 붙여 넣고 [연결 시험하고 저장]
  3. "연결 성공!"이 나오면 끝이에요. 이 컴퓨터는 다음부터 자동으로 내 서버를 써요.

문제가 있으면 무엇이 빠졌는지 알려 줘요 (예: "익명 로그인이 꺼져 있어요"). 다른 컴퓨터에서 방을 만들 때는 6단계만 다시 하면 돼요.
학생은 따로 할 일이 없어요. 선생님 방의 QR·링크에 선생님 서버 정보가 함께 들어가요.
